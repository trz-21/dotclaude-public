# 아카이브 판단 (무인 실행)

이 세션은 dotclaude 동기화가 띄운 무인 실행이다. 사용자에게 질문할 수 없다. 파일은 읽기만 하고, 결과 파일 하나만 쓴다.

## 할 일

후보 목록(candidates.json)의 각 항목을 실제로 열어 읽고, 지금 아카이브할지 판단한다.
후보는 오래 쓰이지 않았다는 이유로 기계적으로 추려진 것이라 전부 아카이브하라는 뜻이 아니다.

항목 id 는 원본 레포 안 경로다 (예: `skills/foo`, `projects/Desktop/x`, `memory/HOME-Desktop-x`)

## 판단 기준

아카이브한다
- 끝난 맥락에 묶인 것: 퇴사한 회사, 끝난 수업·과제, 종료된 프로젝트 전용 스킬·설정·메모리
- 다른 스킬이 역할을 대신하게 된 것
- 원본 프로젝트가 사라진 미러 (`source_exists: false`)
- 오래 안 썼고, 내용상 앞으로 다시 쓸 계기가 보이지 않는 것

남긴다
- 범용 워크플로우라 새 프로젝트·새 작업에서 다시 쓸 가능성이 큰 것 (예: 프로젝트 초기화, 하네스 기반 구현)
- 다른 활성 스킬·훅이 참조하는 것 (원본 레포에서 Grep 으로 참조 여부를 확인한다. 예: 훅이 호출하는 스킬, `_shared` 문서)
- 판단이 애매한 것 (다음 주에 다시 본다)

사용자 배경은 `~/.claude/me/` 와 `~/.claude/CLAUDE.md` 에서 확인할 수 있다 (현재 진행 중인 일, 끝난 일).

## 결과

아래 형식으로 결과 파일을 쓴다. 남기는 항목도 `keep` 에 사유와 함께 적는다.

```json
{
  "archive": [{"id": "skills/foo", "reason": "한 문장 사유 (한국어)"}],
  "keep":    [{"id": "skills/bar",  "reason": "한 문장 사유 (한국어)"}]
}
```
